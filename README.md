# CodeLab: C/C++ Practice IDE

A responsive, English-language browser IDE for practicing C and C++.

## Features
- C and C++ language switching and syntax highlighting
- Editor with line numbers and keyboard shortcut (Ctrl/Cmd + Enter)
- Standard input and program output panels
- Drafts saved locally in your browser
- Responsive layout for desktop and mobile
- Code execution via the external Judge0 Community Edition service

## Run locally
Open `index.html` in a browser or serve the repository with any static web server.

## Deploy to Render
Create a Render **Static Site** connected to this repository:
- Branch: `main`
- Build command: leave blank if accepted, otherwise `echo "Static site"`
- Publish directory: `.`

## Execution and privacy
Execution uses the external Judge0 Community Edition endpoint at `https://ce.judge0.com`. It is not a self-hosted compiler; availability, request limits, and handling of submitted code are controlled by that service. Do not submit passwords, API keys, or private code. The app has no account system or server-side code storage.
